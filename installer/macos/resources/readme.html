After Installation

Open Themisto.app from your Applications folder and complete device enrollment via your organization's dashboard.

Alternatively, enroll from the terminal:

sudo themisto-activate --token <enrollment-token>

Installed Paths

  • /Applications/Themisto.app
  • /usr/local/bin/themisto-agent
  • /usr/local/bin/themisto-service
  • /usr/local/bin/themisto-activate
  • /usr/local/bin/themisto-uninstall
  • /etc/themisto/agent.json
  • /Library/LaunchDaemons/com.themisto.agent.plist

Managing the Agent

  • Start: sudo themisto-service start
  • Stop: sudo themisto-service stop
  • Status: sudo themisto-service status
  • Uninstall: sudo themisto-uninstall
